# 독립 근거 검토서

- 검토유형: `INDEPENDENT | SELF_REVIEW_FALLBACK`
- 거래유형·대상·질문:
- 검토자:
- 검토일:
- 결과: `VERIFIED | VERIFIED WITH WARNINGS | FAILED | INCONCLUSIVE`

## 재현 기록

| 항목 | 원본 파일·출처 | 재현한 필터·계산식 | 검토결과 | 발견사항 |
|---|---|---|---|---|
|  |  |  |  |  |

## 핵심 점검

- 대상, 거래유형, 면적·지번, 기간
- 출처계보와 원문 URL
- 수집목록, 예정·완료 범위, 행 대사, 파일 SHA-256
- 단위, 부가세·비용, 취소·정정, 중복 처리
- 근거경로 분리
- 차트·표·본문·결론 일치
- 감사 지문과 감사 산출 배포상태
- 법률·보증·인허가·적합성 표현의 한계
- `demo`·`actual` 표시
- 미해결 모순 또는 누락자료

## 발견사항

발견사항마다 심각도 `critical`, `major`, `minor`, 영향을 받는 주장, 필요한 수정내용을 기록한다.

## 최종 의견

주 분석자가 원하는 결론을 확인해주지 않는다. 근거와 계산이 고객에게 표시할 주장을 뒷받침하는지만 기록한다.
