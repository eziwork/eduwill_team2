# 독립 근거 검토

사용자가 독립 감사를 요청했거나, 별도 검토자를 사용할 수 있고 작업 권한이 허용할 때만 사용한다.

## 검토자에게 제공할 자료

- 고정된 거래유형, 대상, 고객 관점, 질문, 기준일
- 원본 또는 보존된 근거자료
- 수집목록, 파일 SHA-256, 수집범위·건수 대사
- 정규화 행과 명시적 제외내역
- 계산식과 차트 입력값
- 고객에게 표시할 예정인 주장
- [독립 근거 검토 양식](../assets/independent-evidence-review-template.md)

원하는 결론을 검토자에게 알려주지 않는다. 검토자는 읽기 전용이며 리포트를 대신 고치지 않는다.

## 검토항목

- 출처 식별과 1차 자료 계보
- 대상, 거래·부동산 유형, 면적·지번, 기간, 단위 필터
- 취소, 정정, 갱신, 중복, 부가세, 비용, 결측치 처리
- 모든 중요 계산의 독립 재현
- 정규화자료, 차트, 본문, 결론의 일치
- 결정론적 감사 지문과 HTML 메타데이터의 일치
- 실거래, 현재 공개매물, 공식규정, 비공개 확인자료의 분리
- 감정평가·법률·보증·인허가·적합성 표현의 한계 준수
- `actual`과 `demo` 표시

## 결과 연결

- `VERIFIED`: 표준 배포판정을 계속 진행한다.
- `VERIFIED WITH WARNINGS`: 경고가 해소될 때까지 최대 `PASS WITH CONDITIONS`만 허용한다.
- `FAILED`: `HOLD`로 두고 근거 또는 계산을 고친 뒤 가능하면 재검토한다.
- `INCONCLUSIVE`: 누락자료나 재현 가능한 출처를 확보할 때까지 `HOLD`로 둔다.

별도 검토자를 사용할 수 없거나 권한이 없으면 동일 점검표를 `SELF_REVIEW_FALLBACK`으로 수행한다. 독립 검토로 표현하지 않는다.
