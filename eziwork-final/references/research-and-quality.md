# 근거·출처·품질 기준

## 1. 근거를 네 경로로 분리한다

| 경로 | 포함자료 | 대표 예시 |
|---|---|---|
| `closed_or_reported_transactions` | 체결되었거나 공식 신고된 계약 | 국토교통부 매매·임대차 실거래 |
| `current_public_listings` | 현재 공개된 희망조건 | 네이버페이 부동산 공개매물 |
| `official_rules_and_status` | 법률·행정·등기·허가·보증 규정과 상태 | 정부, 등기기관, 보증기관, 지자체 |
| `field_or_private_confirmations` | 공개자료로 확정할 수 없는 사실 | 소유자 확인, 중개사 현장점검, 고객 보유 건축물대장 |

서로 다른 경로를 하나의 평균으로 합치거나, 한 경로가 다른 경로까지 증명한다고 표현하지 않는다.

## 2. 출처등급

- `S1`: 공식 원자료 또는 공식기관 페이지
- `S2`: 현재 공개 플랫폼 매물·서비스 페이지
- `S3`: 사업자가 직접 확인한 자료 또는 사용자 제공자료
- `S4`: 맥락 설명에만 쓰는 2차 자료

가격·계약조건 결론은 S1·S2를 우선한다. 법률, 보증, 등기, 용도, 허가 주장은 해당 공식출처가 필요하다. 검색결과와 AI 요약은 출처를 찾는 도구이지 최종근거가 아니다.

## 3. 필수 출처기록

표시하는 데이터그룹마다 다음을 기록한다.

- 출처 ID와 등급
- 운영기관·출처명
- 원문 URL 또는 `내부 확인 기록 · 외부 링크 없음`
- 조회일시와 기준일
- 대상, 면적·타입, 거래유형, 기간과 필터
- 단위와 부가세·관리비 포함기준
- 제외, 정정, 취소, 중복 처리
- 가능한 경우 화면 또는 로컬 파일경로
- 알려진 한계

인증정보, 키, 쿠키, 세션토큰, 개인정보는 노출하지 않는다.

`actual` 리포트는 설명문만으로 출처기록을 대신할 수 없다. [근거 감사 스키마](evidence-audit-schema.md)의 출처·근거그룹 목록에 구조화하고, 참조파일을 보존하며 모든 SHA-256을 검증한다.

## 4. 네이버페이 부동산 수집범위

고객 또는 중개사가 실행하는 단일 대상 중심의 제한 조회만 사용한다. 의사결정에 필요한 소수 매물을 확인하고 조회시각과 필터를 기록한다.

- 전체 지역이나 전체 서비스를 크롤링하지 않는다.
- 로그인, CAPTCHA, robots, 속도제한, 차단을 우회하지 않는다.
- 접근이 막히면 중단하고 저장한 내보내기 파일이나 화면을 요청한다.
- 중복을 명시적으로 대사하지 않았다면 광고건수는 매물건수가 아니라 광고기록 건수다.
- 현재 카드, 확인일, 참고시세 차트로 과거 호가추이를 만들어내지 않는다.

아파트 매매에는 이 스킬의 [아파트 시장자료 수집](apartment-market-data-collection.md) 절차와 정규화·무결성 규칙을 적용한다.

## 5. 공식자료의 적용범위 확인

자료를 쓰기 전 다음이 모두 맞는지 확인한다.

- 거래유형: 매매, 전세, 월세, 상가 임대, 토지 임대
- 부동산 유형: 아파트, 빌라, 사무실, 상가, 토지 등
- 계약일과 신고상태
- 면적과 가격단위
- 취소·정정의 의미

공개자료가 부족하거나 적용되지 않으면 `공개 자료 부족`이라고 적는다. 사용자 제공 계약·매물·현장기록은 해당 근거경로에서만 사용하고 표현범위를 좁힌다.

## 6. 계산 규칙

- 집계 전 원본 행을 보존한다.
- 건수, 중위값, 최저, 최고, 가중평균, 단순평균 중 사용한 통계를 밝힌다.
- 가격표본이 치우치면 중위값을 우선하고 집계값에는 건수를 함께 표시한다.
- 누락기간을 보간하지 않는다.
- 면적, 층, 부가세, 관리비 포함기준이 다른 자료는 차이를 표시하지 않고 비교하지 않는다.
- 환산계산은 식과 가정을 표시한다.
- 반올림은 계산 후에만 하며 내부에는 원값을 보존한다.
- 0건 조회도 근거다. 기간이나 지역을 조용히 넓히지 않는다.
- 계산표시값은 같은 근거그룹에 등록된 해시 검증 파일에서 선택한 JSON 입력객체로 산출한다. 차트·초안·과거 리포트의 값을 손으로 옮기지 않는다.

## 7. 배포판정

먼저 `scripts/audit_evidence.py`를 실행한다. 아래는 결과의 의미이며, 최종상태는 작성자가 아니라 스크립트가 정한다.

### PASS

중요 주장을 모두 추적할 수 있고, 필터와 단위가 일치하며, 리포트를 재현할 수 있다.

### PASS WITH CONDITIONS

핵심 비교는 유효하지만 시차가 있거나 현장확인이 필요한 항목이 남아 있다. 리포트에 한계와 다음 확인행동을 표시한다.

### HOLD

다음 중 하나라도 있으면 중단한다.

- 대상 또는 거래유형 불일치
- 표시된 중요 숫자의 출처 누락
- 취소·정정·중복·단위·부가세·비용 처리 미해결
- 교육용 값을 실제값으로 표시
- 공식 또는 개별 근거 없이 법률·보증·용도를 확정
- 깨진 출처링크, 누락된 로컬 파일, 모순되는 요약

`HOLD` 상태에서는 고객용 PDF를 출력하지 않는다.

## 8. 최소 QA 기록

산출물 옆에 간결한 Markdown 또는 JSON 기록을 저장한다.

- 고정된 분석범위
- 출처와 조회조건
- 정규화 행수
- 계산식과 제외내역
- 미해결 확인사항
- 배포상태와 검토자
- 생성한 HTML·PDF 경로와 기준일
