# 매거진형 투자분석 브리핑

가격 설명을 넘어 투자 관점의 읽기 흐름이 필요할 때 이 변형을 사용한다.

## 서사 순서

1. 의사결정 질문 하나, 실제 부동산 이미지, 짧은 편집자형 도입문으로 시작한다.
2. 숫자보다 장소를 먼저 설명한다. 지도는 투자성이 좋다는 근거가 아니라 현장답사 안내로 사용한다.
3. 체결 실거래, 현재 공개매물, 고객 가정을 분리한다.
4. 투자 의견에 앞서 가격흐름과 거래 유동성을 읽는다.
5. 강점, 위험, 누락 입력, 계약 확인사항, 다음 행동으로 마무리한다.

## 문장 방식

- 차분한 서사 흐름의 설명형·칼럼형 문장을 사용한다.
- 끊어진 짧은 항목보다 서로 이어지는 2~3개 문단을 우선한다.
- 크고 간결한 질문형 또는 결론형 제목을 사용한다.
- 차트마다 `무엇이 보이는가`, `무슨 의미인가`, `무엇이 아직 불명확한가`, `다음에 무엇을 확인할 것인가`를 연결한다.
- 상승, 수익률, 안전성, 유동성, 적합성을 보장하지 않는다.

## 시각자료와 근거

- 가능하면 실제 정적 지도 화면을 사용한다. 인쇄 레이아웃에서 불필요한 조작버튼을 제외하고 제공자 표시는 유지한다.
- 근거 페이지마다 핵심 시각자료 하나를 두고 장식용 차트를 피한다.
- 제공자, 기준일, 표본범위, 한계를 시각자료 바로 아래에 표시한다.
- 실거래, 공개매물 표본, 맥락 이미지, 고객 가정을 시각적으로 구분한다.
- 일반적인 현장점검 조언만 되풀이하는 사이드바를 넣지 않는다. 대상 고유 근거나 본문에 없는 구체적 비교가 있을 때만 측면주석을 사용한다.
- 표준 요청검증과 근거감사를 통과한 후에만 매거진 생성기를 실행한다.

## 생성

표준 생성기와 동일한 검증 요청 스키마로 `scripts/build_magazine_report.py`를 실행한다. 섹션의 `layout`은 `prologue`, `map`, `chart`, `matrix` 중 하나로 지정한다. 첫 섹션은 보통 `prologue`이며 생성기는 이를 의사결정 개요 앞에 배치한다.
